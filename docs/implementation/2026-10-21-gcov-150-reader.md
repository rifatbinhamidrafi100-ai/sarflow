# GCOV 1.5.0 reader and real-product verification

The existing reader now supports GCOV specifications 1.2.1 and 1.5.0.
This is format and measurement-support compatibility, not event validation.

## Specification review

Reference: JPL D-102274 Rev F, July 8, 2026, version 1.5.0, obtained through
the [official ASF GCOV guide](https://nisar-docs.asf.alaska.edu/gcov/).
Local copy: `artifacts/gcov-150-review/GCOV-RevF.pdf`.

- Section 4.3.3 (printed page 25) retains subswath mask codes 1–5 as valid,
  0 as invalid/partially focused, and 255 as outside acquisition support.
- Table 5-3 (printed page 36) defines `inputDataExceptionMask` as a bitwise
  exception code: zero means no anomaly. All nonzero codes are excluded.
- Table 5-6 documents the RTC output normalization/expression conventions
  and processing flags. The downloaded 1.5.0 product explicitly declares
  `gamma0` and `Linear power`; this label is accepted as linear power.
  Amplitude, decibel, missing, and unknown expressions remain rejected.

Unknown product specifications remain rejected. Specification 1.5.0 requires
the additional exception mask for valid support; a missing mask makes all
pixels unavailable. Malformed shape or unsigned-byte type is rejected.

# Investigation delivery implementation

Continue the authorized roadmap in the recovered working copy. Preserve existing pages and scientific processing. Extend the shared evidence package into deterministic bilingual explanations, a quality inspector, native-grid hotspot groups, a client-generated PDF report, a self-contained offline HTML brief, and a browser-local saved investigation collection. None of these establishes a validated hazard workflow or independent reference agreement.

## Contract and scope
- English and Bangla use fixed evidence templates, not an external model. Explanations read the same package as exports. Reject unsupported numbers, and do not answer damage/casualty/prediction questions with a change summary.
- Hotspots group same-sign changed cells using four-neighbor connectivity. Report exact native-cell extents/counts and row-run rectangles. Do not imply geographic polygons without an exact supported geotransform.
- Quality includes selected dates, common/excluded support, available acquisition count, units, CRS, polarization, missing pixel-area/resolution information, and calibration/validation status.
- Reports contain an explicitly native-grid change-mask snapshot, provenance, method and warnings. Generate PDF locally via a dynamically loaded library. Offline HTML contains no scripts or external assets and is bounded in size; it does not claim the whole app works offline.
- Saved entries store complete evidence plus notes/hypothesis locally, bounded to five investigations and 4 MB serialized storage. No automatic save, external upload, community verification, or automatic reclassification. Validate and recompute imported/saved packages; never trust stored derived metrics.

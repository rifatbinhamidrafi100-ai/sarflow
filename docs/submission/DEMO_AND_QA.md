## Copy-ready judge answers

**Which NASA data do you use?**

NISAR GCOV collection metadata through NASA CMR and the NISAR geocoded polarimetric covariance browse layer through NASA GIBS. The local calibrated-data path is separate and still needs a completed actual observation run.

**Is this real satellite data?**

The browse imagery and observation metadata are real source products. The teaching analysis uses synthetic numerical grids. This version has no validated quantitative disaster result.

**Is it dynamic?**

Source discovery can request newly available catalogue records and browse dates. The visible global-radar page checks approximately every five minutes. Bundled archives and the optical 2024 background are static. Satellite acquisition and publication delays remain visible; this is not live video.

**Will it automatically detect the next flood?**

No deployed continuous, scientifically validated flood-alert service is established. A separate local worker can monitor configured places while running; it still requires suitable calibrated inputs, masks and validation.

**What AI model detects flooding?**

No runtime generative model or trained flood model is used. The experimental water workflow is rule-based. The English/Bangla assistant uses deterministic evidence templates. Codex assisted development; that does not validate the results.

**What accuracy did you achieve?**

No defensible real-world accuracy figure is available yet. Software tests check implementation behavior with fixtures; they do not measure detection accuracy. We need a suitable independently labeled evaluation series.

**Why not calculate change from the image colors?**

Rendered colors are a visualization chosen by a service. Quantitative analysis requires compatible calibrated measurements, geometry, masks and documented processing.

**Do Sentinel-2 and NISAR measure the same thing?**

No. The Sentinel-2 cloudless layer is optical geographic context, clearly attributed as a 2024 mosaic. It is not subtracted from radar as a generic numerical change signal or relabeled NISAR.

**What is your strongest current contribution?**

The interaction connects location discovery, dated source observations, explicit evidence status, accessible explanations and portable reporting. Its scientific credibility depends on preserving those distinctions and completing the real-data evaluation.

**Can it scale to the entire Earth?**

Global discovery is supported where source coverage exists. Heavy calibrated processing is currently a bounded local workflow with a single worker. Distributed processing, scalable caches and cloud-derived products remain future engineering work.
